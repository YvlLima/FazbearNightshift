# Política de Privacidade — Fazbear Nightshift

_Última atualização: 15 de agosto de 2026_

Esta Política de Privacidade explica que dados o bot **Fazbear Nightshift** ("o Bot") recolhe, como são usados, e como são armazenados.

## 1. Dados Recolhidos

Ao utilizar o Bot, os seguintes dados podem ser armazenados:
- **ID de utilizador do Discord** (identificador único, não o teu nome de utilizador nem email).
- **Estatísticas de jogo**: vida atual (HP), animatronic atribuído, número de derrotas causadas a outros jogadores (kills), estados temporários de jogo (ex: envenenado, cego, invencível), e o timestamp do último ataque (para gerir cooldowns).

Não recolhemos: emails, números de telefone, endereços IP, mensagens escritas nos servidores, ou qualquer dado pessoal identificável para além do ID do Discord.

## 2. Finalidade dos Dados

Os dados recolhidos são usados exclusivamente para:
- Permitir o funcionamento das mecânicas de jogo (duelos, vida, cooldowns, leaderboard).
- Exibir estatísticas ao próprio utilizador através dos comandos `/status` e `/leaderboard`.

## 3. Armazenamento

Os dados são armazenados numa base de dados local associada ao Bot, e não são partilhados, vendidos ou transferidos a terceiros.

## 4. Retenção de Dados

Os dados de um jogador são mantidos enquanto o Bot estiver ativo no servidor onde o utilizador jogou. Podem ser apagados periodicamente em caso de reset de temporada ou manutenção do Bot.

## 5. Direitos do Utilizador

Podes solicitar a remoção dos teus dados de jogo (HP, kills, animatronic atribuído) a qualquer momento, contactando o desenvolvedor do Bot através do Discord.

## 6. Partilha com o Discord

O Bot opera através da API do Discord e está sujeito também à Política de Privacidade do Discord (https://discord.com/privacy). A utilização do Bot implica a aceitação dos termos da plataforma Discord.

## 7. Alterações a Esta Política

Esta política pode ser atualizada periodicamente. Alterações significativas serão refletidas na data de "última atualização" no topo deste documento.

## 8. Contacto

Para questões relacionadas com privacidade ou pedidos de remoção de dados, contacta o desenvolvedor através do Discord.
